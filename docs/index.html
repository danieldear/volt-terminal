Dock it. Float it. Close it.

The work stays in one place.

Volt gives you project context without turning the terminal into a dashboard. Open what you need; leave the rest of the screen to your tools.

Know what changed.

Check Git changes, your current branch, worktrees, and available project workflows from a single compact card.

Give your editor the window.

Dock the card beside the terminal, or float it over the window so Neovim and other full-screen tools keep every column.

Find it without leaving.

Search visible and retained terminal output, then use workspace search for files, text, branches, and worktrees.

Keep sessions legible.

Color and rearrange tabs, split panes, and tune the font, line height, and theme to suit long working sessions.

Security, stated plainly.

Volt is early software. Its safeguards are useful, but none is a substitute for reviewing what you run or reporting a flaw privately.

Secure input has limits.

On macOS, Volt can request Secure Event Input for a focused no-echo prompt, with a manual toggle for other cases. It does not hide terminal output, erase shell history, or protect the clipboard. Read the security policy.

Public code, checked changes.

The public repository requires a pull request and passing CI on main, including tests, dependency audit, and secret scanning. GitHub push protection and private vulnerability reporting are enabled. These checks cannot guarantee that Volt has no vulnerabilities. See the publication review.

What we're working on.

Our priorities are simple: make the terminal dependable, make the public release easier to trust, then build on top of that foundation.

Now

  • Public feedback on the early preview
  • Terminal correctness and secure input hardening
  • Rendering and input regression testing

Next

  • Developer ID signing and notarization
  • Terminal protocol compatibility
  • More repeatable performance comparisons

Exploring

  • Optional AI context and local-model workflows
  • Deeper project-aware actions
  • Broader platform support after macOS matures

Suggestions and bug reports belong in GitHub Issues. Features listed under “Exploring” are not shipped.

Get Volt.

Explore the v0.1.8 public preview or build it locally. The release includes a macOS app ZIP and a Linux binary archive. The macOS build is ad-hoc signed, not notarized, so Gatekeeper may block it; a notarized build is planned.

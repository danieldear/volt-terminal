Context when you want it. Space when you don't.

The terminal comes first.

Volt’s workspace tools sit beside the shell, not in its way. Close or float the card when your editor needs every column.

▦

GPU-rendered text

Metal-backed rendering on macOS, with Nerd Font fallback and configurable font and line height.

⌘

Native workflow

macOS menus, tabs, pane splits, text selection, Find, and familiar keyboard controls.

⌁

Workspace context

A compact card for Git changes, branches, worktrees, workflows, and local tooling when available.

⌕

Search in place

Find retained terminal output, or search workspace paths, text, branches, and worktrees.

◈

Make it yours

Switch built-in themes or edit and save custom themes with a live preview.

♧

Built in the open

MIT-licensed Rust source, reproducible CI checks, and a public roadmap with honest platform status.

What comes next.

Direction, not a promise of dates. Terminal correctness and safety stay ahead of extra features.

Now

  • Security review and secure input behavior
  • Public-release readiness and documentation
  • Rendering and input regression testing

Next

  • Developer ID signing and notarization
  • Terminal protocol compatibility
  • More repeatable performance comparisons

Exploring

  • Optional AI context and local-model workflows
  • Deeper project-aware actions
  • Broader platform support after macOS matures

Suggestions and bug reports belong in GitHub Issues. Features listed under “Exploring” are not shipped.

Try Volt.

Download the macOS build, or build from source. Volt is still early software; the current macOS release archive is ad-hoc signed, not notarized. Read the release notes before installing.

Get the macOS buildRead the guide
Build from source · Rust 1.87+
$ git clone https://github.com/danieldear/volt-terminal.git
$ cd volt-terminal
$ cargo build --release
$ ./target/release/volt

macOS needs Xcode Command Line Tools. Linux builds are available, but the UI is not yet a supported daily-driver target.

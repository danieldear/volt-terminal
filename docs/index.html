$ volt

A fast, native terminal for macOS and Linux.

Volt is written in Rust and draws every frame on the GPU, so it stays smooth under heavy output. Run your project's tasks with one click, search your scrollback and your whole project from one box, and keep work side by side in tabs and split panes.

Performance

GPU rendering

Text is drawn on the GPU through wgpu: Metal on macOS, Vulkan or OpenGL on Linux. Glyphs are cached and unchanged lines are reused, so heavy output stays smooth.

Paced to your display

Frames are synchronized with the display's refresh rate, so scrolling and redraws don't tear.

Any monospaced font

Nerd Font icons and powerline symbols fall back automatically. Font size, line height and padding are adjustable.

Appearance and settings

Five built-in themes

Catppuccin Mocha, Tokyo Night Storm, Gruvbox Dark Hard, Nord and Dracula. Switching applies to every window at once.

Live theme editor

Change any of the 22 colors and watch your terminal update as you type. Save the result as your own theme.

Themes as plain files

Saved themes are small TOML files in ~/.config/volt/themes, easy to share or keep with your dotfiles.

One settings file

Everything lives in a commented config.toml. Edit it and reload without restarting. Keyboard shortcuts can be remapped there too.

Your editor, per file type

Choose nvim, nano or any editor, per file type. Search results open in it at the matching line, right in the current tab.

Search the whole project without leaving the prompt.

Press ⌘ F to search everything the terminal has printed, all the way back, plus file names, file contents, and your Git branches and worktrees — or narrow it to one of them.

  • Matches are highlighted in every result as you type.
  • Enter opens a file in your editor at the matching line, or jumps to the matching line of output.
  • Search runs on your machine. Nothing is sent anywhere.

Your project's commands, one click away.

Save build, test, run and deploy commands in .volt/tasks.toml. They appear as buttons and run right in your current tab, with ✓ or ✗ when they finish if shell integration is on. Enable it for Zsh or Bash from View → Enable Shell Integration (This Tab).

  • Add tasks from a form, or import the ones Volt finds in Cargo.toml, package.json and other project files.
  • A tasks file that arrives with a clone is reviewed before anything runs, and again whenever it changes.
  • Volt won't type over a running command, a full-screen app or a password prompt.

Password prompts are protected automatically.

On macOS, when a program asks for a password, Volt turns on Secure Keyboard Entry so other apps can't read what you type, and shows a lock while it's on. You can also switch it on yourself from the Volt menu.

  • Programs can't write to your clipboard.
  • Pasting is always your action, and very large pastes are refused.
  • Titles that programs set are stripped of hidden control characters.

Secure Keyboard Entry stops other apps reading your keystrokes. It doesn't hide what's on screen, clear shell history, or protect the clipboard. Found a security issue? Report it privately.

Status and roadmap.

Volt 0.1.11 is an early public preview. Here is what works in the current release, and what we are building next. Settings and shortcuts may still change before 1.0.

Available today

  • GPU rendering with a cached glyph atlas
  • Tabs and splits, with colored, reorderable tabs
  • ⌘F search across scrollback, files and folders
  • Project tasks from .volt/tasks.toml
  • Workspace card for the current folder and Git status
  • Themes and a live theme editor
  • Shell integration: prompt jumps, task status, inherited folders
  • Clickable links, including OSC 8
  • Configurable shortcuts and a per-file-type editor
  • Secure keyboard entry for passwords

Install Volt.

Download a release for your platform, or build from source. Each release lists SHA-256 checksums in SHA256SUMS.txt. New macOS releases require Developer ID signing and Apple notarization before publication. Check the signing status included with your download; older preview archives were ad-hoc signed.

macOS

  1. Download the app

    Get the latest macOS zip from GitHub Releases.

    Download for macOS

  2. Move it to Applications

    Unzip the download and drag Volt.app into your Applications folder.

  3. Approve the first launch

    Verify the download and checksum, then open Volt. The release includes its verified signing status. If macOS warns about an older preview or a damaged download, stop and review the release guidance; do not disable Gatekeeper or quarantine globally.

Linux

Download the x86_64 archive from GitHub Releases, then extract and run it:

$ tar -xzf Volt-*-linux-x86_64.tar.gz $ ./Volt-*-linux-x86_64/volt

Build from source

For Intel Macs, other Linux architectures, or to try changes before they're released.

$ git clone https://github.com/danieldear/volt-terminal.git $ cd volt-terminal $ cargo build --release $ ./target/release/volt

Needs Rust 1.87 or later, plus the Xcode Command Line Tools on macOS or libudev-dev on Linux. The README covers configuration, themes and keyboard shortcuts.

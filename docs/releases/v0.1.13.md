# Volt v0.1.13

## Changes

- Integrate pinned Volt UI Kit 0.4.0: right-aligned switches, selectable choices,
  editable fields and opacity sliders, while preserving Apply/Cancel previews.
- Improve Settings and onboarding mouse/keyboard interaction and control icons.
- Add synchronized terminal output (DEC 2026), opt-in extended keyboard reporting,
  command-output selection/reflow anchors and optional session layout restoration.
- Improve native macOS IME handling without changing ordinary shell input.
- Preserve the existing terminal renderer and current-pane trusted task workflow.

## Validation and limits

The UI update passed 707 Rust tests, 36 Python checks, strict Clippy, Rust 1.87
checks, 425 GPU fixture cases and targeted native Settings interaction tests.
Toolkit-inclusive tests use a documented test-only stack allowance.

Rendering performance acceptance is **not passed**: the repeated offscreen
Unicode full-redraw CPU median increased about 18% against the saved pre-upgrade
binary. This is not a measured full-terminal throughput regression, but it must
not be presented as performance-neutral. See [measurement details](../ui-toolkit-migration.md).
Matched full-app benchmarks and cross-system testing remain outstanding.
Linux packages are CI-tested; native Linux validation is deferred.

Release assets must be built from the merged tag. The macOS workflow is configured
for Developer ID signing and notarization and must pass Apple acceptance,
stapling and Gatekeeper checks before packaging. See the release asset
`macos-signing-status.txt` for the actual signing mode; local development builds
remain ad-hoc signed.

# Volt v0.1.16

## Highlights

- Workspace cards now use semantic content blocks with one icon per item,
  natural text wrapping, variable-height scrolling and shared hit geometry.
- Tasks have a structured command review dialog and an explicit, separate
  file-permissions review. Exact-file trust, busy-shell, secure-input and
  full-screen guards remain enforced. `confirm = true` asks before every run.
- Theme editing adds saturation/value and hue controls, RGB sliders, color
  presets and live preview. Hex entry remains available; Cancel restores the
  previous theme and saving remains explicit.
- Partial shell configurations preserve the login-shell default, preventing
  omitted arguments from skipping normal shell/Homebrew initialization.
- The existing macOS build helper signs local bundles, installs the single
  Volt.app, keeps a recovery copy of the previous app and refuses to overwrite
  a running bundle. No separate development installation is required.

## Performance and validation

The maintainer reports TermMarkV2 totals of 22.2787s and 22.6466s on an Apple M4
Pro. These are local user measurements, not a controlled comparative benchmark
or a guarantee on other systems. Layout and UI geometry remain cached; hidden
cards do not add layout/drawing work.

CI validates formatting, strict Clippy, default workspace tests, Python
validation, renderer fixtures, MSRV, dependency vulnerabilities and secret
scanning before merge. The release workflow validates its own tagged source.

## Distribution and experimental scope

The public macOS artifact requires Developer ID signing, Apple notarization and
stapling. Linux x86_64 archives are also built; native Linux desktop behavior has
not been manually validated by the maintainer.

The new toolkit GPU Settings host remains explicitly opt-in and is not compiled
into the default release. It does not replace the terminal renderer. Upstream
toolkit-native SF font-alias/weight tests fail on the macOS 26 hosted image; that
text-shaping path is not used by Volt's production UI or glyph-transfer bridge.

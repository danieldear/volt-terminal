# Volt v0.1.14

## Highlights

- **Less Unicode allocation churn:** reuse row-cache grapheme buffers when output
  changes, instead of repeatedly freeing and recreating unchanged strings.
  Emoji, combining text, styles, links and glyph placement are preserved.
- **UI Kit 0.4.0 controls:** right-aligned switches, selectable choices, editable
  fields and opacity sliders, with transactional Settings previews/Apply/Cancel.
- **Terminal compatibility:** synchronized output (DEC 2026), negotiated extended
  keyboard reporting, command-output selection/reflow anchors, optional layout
  restoration and native macOS IME fixes. These arrived in the v0.1.13 testing
  draft and are included in this public release candidate.

## Performance and validation boundaries

The maintainer tested the fixed real app, reported results near **23 seconds**
and explicitly accepted it for release. This is user-reported acceptance, not
an independent matched trial set. Offscreen Unicode full redraw improved in all
four fix comparisons; the identical-binary control also demonstrated substantial
measurement variance. Historical failed batches remain documented and are not
relabeled as passes. No benchmark threshold was relaxed and no universal terminal
speedup is claimed. See [the investigation](../unicode-rendering-performance.md).

The fix passed 710 Rust tests, 36 Python validations, strict workspace/all-target
Clippy, Rust 1.87 all-target checks and 512 GPU cases, including cached/full and
linked/plain pixel equality. Toolkit-inclusive tests use a documented test-only
stack allowance. Linux packages are CI-tested; native Linux validation remains
deferred. Broader accessibility and daily-driver acceptance remain ongoing.

Release assets must come from the exact merged main tag and pass their own CI.
macOS distribution requires Developer ID signing, Apple acceptance, stapling and
Gatekeeper checks. Verify `macos-signing-status.txt` and the SHA-256 checksums;
local development bundles are not substitutes for notarized release artifacts.

# Volt v0.1.15

## Highlights

- Refresh the pinned **Volt UI Kit 0.4.0** snapshot from merged upstream commit
  `000c5d083562c67d7fd6392f128b63efc827f201`, including chart path-limit fixes,
  updated toolkit documentation and compatibility with newer Rust tooling.
- Raise the source-build minimum to **Rust 1.89** and clear Rust 1.98 Clippy lints.
- Preserve existing Settings controls, terminal input, Unicode buffer reuse and
  Volt's active **wgpu 29** renderer. The toolkit's optional Vello 0.11 / wgpu 30
  native host is not enabled in Volt.

## Validation and distribution

The integrated source passed 717 Rust tests/doc-tests, 36 Python validations,
512 GPU fixture cases, strict Clippy, Rust 1.89 checks, dependency/secret scans
and native macOS settings/tab/Unicode smoke testing. Release CI validates the
exact tagged source again on Linux and macOS. Toolkit-inclusive tests retain
the documented test-only stack allowance. Native Linux testing is deferred.

No new full-app TermMark comparison was run for this integration, and no
throughput improvement is claimed. The previously released Unicode allocation
fix and historical performance evidence remain intact.

macOS artifacts require Developer ID signing, hardened runtime, Apple
notarization, stapling and downloaded-ZIP Gatekeeper verification. Check
`macos-signing-status.txt` and `SHA256SUMS.txt`.

The separate toolkit repository's hosted CI is blocked before test execution
by account billing/spending settings; its local feature, packaging and Metal
checks passed. Volt's own release CI is the distribution gate.

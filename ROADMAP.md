# Volt roadmap

The maintained feature/status roadmap is [docs/ROADMAP.md](docs/ROADMAP.md).

For delivery order, dependencies, performance budgets and acceptance checks, see
[the execution plan](docs/terminal-execution-plan.md).

| Priority | Focus |
| --- | --- |
| P0 | Correctness, security/performance acceptance, existing task/tab reliability and publication of a notarized release. |
| P1 | Synchronized output, extended keyboard reporting, command-output selection and accessibility/IME fixes. |
| P2 | Layout restoration, richer shortcuts, Linux usability, link hover and security-gated clipboard requests. |
| P3 | Optional ligatures, inline graphics, quick terminal, automation and AI tooling. |

Signing/notarization is implemented and the public v0.1.16 release is available.
The current unreleased [product-readiness batch](docs/product-readiness.md)
records implementation and remaining native/platform acceptance separately.
